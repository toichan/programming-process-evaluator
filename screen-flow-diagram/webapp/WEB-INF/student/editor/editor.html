課題情報

じゃんけん判定プログラム

ユーザーの入力に応じて、勝敗または入力エラーを表示するプログラムを作成します。

実装する機能
  • 入力値を受け取る
  • 条件分岐で勝敗を判定する
  • 不正な入力時に案内を表示する
入力制限

入力は「グー」「チョキ」「パー」のいずれかを想定します。

想定入出力
入力: パー
出力: あなたの勝ち
入力: ぐー
出力: グー・チョキ・パーを入力してください

Pythonコマンド仕様

input()

文字列を受け取るための関数です。

player = input("手を入力してください: ")
if / elif / else

条件によって処理を分岐する構文です。

if player == "グー":
    print("..." )
elif player == "パー":
    print("..." )
else:
    print("..." )
