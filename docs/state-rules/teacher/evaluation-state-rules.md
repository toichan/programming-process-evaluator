# 教師向け評価状態ルール

## 対象

- 教師評価一覧
- 提出物の評価画面
- 評価進捗管理
- 再評価・要修正の判定

## 1. 目的

この文書は、教師向け評価画面における状態定義、遷移条件、表示差分、例外処理を定義する。評価は提出物の状態を管理する基準として扱う。

## 2. 状態語彙

- 未評価
  - 提出はあるが、教師による評価が未実施の状態。

- 評価中
  - 教師が評価を実施中または途中保存した状態。

- 評価済み
  - 評価結果が確定した状態。

- 要修正
  - 提出物に改善が必要と判定された状態。

- 再評価対象
  - 変更後の再確認が必要な状態。

- 非対象
  - 対象外の提出物や対象学生の状態。

## 3. 状態遷移

| 現在状態 | 遷移先 | 条件 |
|---|---|---|
| 未評価 | 評価中 | 評価を開始したとき |
| 評価中 | 評価済み | 評価を確定したとき |
| 評価済み | 要修正 | 改善が必要と判断したとき |
| 要修正 | 再評価対象 | 再提出または再確認が必要になったとき |
| 再評価対象 | 評価済み | 再評価を完了したとき |

## 4. 表示差分

### 4-1. 一覧画面

- 未評価: 「未評価」バッジを表示
- 評価中: 「評価中」表示
- 評価済み: 「評価済み」表示
- 要修正: 「要修正」表示
- 再評価対象: 「再評価対象」表示

### 4-2. 評価詳細画面

- 未評価: フォーム入力可能
- 評価中: 途中保存状態を表示
- 評価済み: 判定結果と振り返り欄を表示
- 要修正: 修正指示の欄を表示

## 5. 操作可否マトリクス

| 状態 | 評価開始 | 編集 | 確定 | 再評価 | 再提出依頼 |
|---|---|---|---|---|---|
| 未評価 | 可 | 可 | 可 | 不可 | 可 |
| 評価中 | 不可 | 可 | 可 | 条件付き可 | 可 |
| 評価済み | 不可 | 条件付き可 | 不可 | 可 | 可 |
| 要修正 | 可 | 可 | 可 | 可 | 可 |
| 再評価対象 | 可 | 可 | 可 | 可 | 可 |

## 6. 例外処理

### 6-1. 既に評価済みの物に再評価依頼が来た場合
- 既存の評価結果を保持し、再評価履歴として追加する。
- 画面上では「再評価済み」と明示する。

### 6-2. 提出物がない場合
- 評価対象として扱わず、一覧から除外するか未対象表示にする。

### 6-3. 提出期限を超えた場合
- 初回提出は課題の期限後提出設定が許可の場合だけ受理し、期限超過を明示する。
- 期限後の再提出は許可しない。
- 既存の提出物は参照可能にする。

### 6-4. 評価開始後に新しい提出版が追加された場合
- 処理中または完了済みの評価は取り消さず、元の提出版に紐づく履歴として保持する。
- 新しい提出版は別の評価対象として扱い、以前の評価結果を上書きしない。
- 教師画面では提出版と評価の対応を確認できるようにする。
- 最新提出版が評価中の場合はその状態を主表示し、直前の完了済み評価を提出版付きの「前回の評価」として併記する。

### 6-5. 評価処理が失敗した場合
- 同じ提出版を対象に評価処理だけを再試行し、生徒へ再提出を要求しない。
- 失敗した評価を保持し、再試行は新しい評価履歴として追加する。
- 教師画面では失敗と再試行中を区別して表示する。

## 7. 実装時の優先順

1. 未評価と評価済みを明確に分ける
2. 評価中の途中保存を定義する
3. 要修正と再評価対象を区別する
4. 一覧表示のバッジを揃える
5. 再評価の履歴扱いを定義する

## 8. 実装に向けた注意点

- 教師用評価状態は、学生側の結果状態と同一にしない。
- 途中保存は「評価中」として区別し、確定済みと混同しない。
- 再評価対象は履歴管理と紐づけて設計する。

## 9. DB状態との同期（IC-004）

- 評価状態の正本は、提出版ごとの評価履歴が持つ評価状態（未評価 / 評価中 / 評価完了 / 失敗 / 要修正）とする。参加記録側の評価状態表示は、この正本を複製した値として同一トランザクション内で同期する。
- 本画面の語彙との対応：「未評価」＝未評価、「評価中」＝評価中（手動評価の途中保存を含む）、「評価済み」＝評価完了、「要修正」＝要修正、「再評価対象」＝新しい再評価用の評価履歴が未評価または評価中の状態。
- 再評価の実行は、既存の評価完了済み履歴を保持したまま、新しい評価履歴（再評価種別）を追加して遷移させる。表示専用の評価状態は、対象提出版に紐づく最新の評価履歴から導出する。
- 評価開始後に新しい提出版が追加された場合、以前の提出版の評価履歴は変更せず、新しい提出版に対して新規の評価履歴を作成する。一覧では最新提出版の評価状態を主表示し、直前の完了済み評価を提出版付きで併記する。
