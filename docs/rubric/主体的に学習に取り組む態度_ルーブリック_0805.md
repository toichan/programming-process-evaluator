# 主体的に学習に取り組む態度 ルーブリック 8.5

| |課題への粘り強さ|課題解決への意欲|
|--|--|--|
|レベル5|- 自力で多くの実行を繰り返しながら課題に取り組み、困難な問題も最後まで諦めずに解決しようと努力している。 <br> - 解決策を複数検討し、効果的なものを選択しようとしている。|- エラーメッセージや実行結果を分析し、問題の本質を理解しようと努めている。<br> - 効率性や可読性を高めるためのコードの改善を積極的に行っている。|
|レベル4|- 自力で課題に粘り強く取り組み、困難な問題も解決に向けて努力している。 <br> - 解決策をいくつか検討し、より良いものを選択しようとしている。|- エラーメッセージや実行結果を分析し、問題の理解に努めている。<br> - コードの改善への工夫が見られる。|
|レベル3|- 指示された課題に自力で取り組み、問題解決に向けて努力している。 <br> - 問題解決のために、いくつかの解決策を検討している。|- エラーメッセージや実行結果から、問題点を把握しようとしている。<br> - コードの改善が見られる。|
|レベル2|- 課題に自力で取り組むものの、途中で諦めてしまうことが多い。<br> - 解決策を検討するものの、表面的な修正にとどまっている。|- エラーメッセージを正しく理解できてない。<br> - コードの改善に取り組んでいる。|
|レベル1|- 課題にほとんど取り組もうとしない。<br> - 解決策を検討せず、安易に人に聞いたり、答えを写したりする。|- エラーメッセージを無視する、または意味を理解しようとしない。<br> - コードの改善がほとんど見られない。|
