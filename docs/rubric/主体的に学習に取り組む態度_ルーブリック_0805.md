# 主体的に学習に取り組む態度 ルーブリック 2026.7.30

| |課題への粘り強さ|課題解決への意欲|
|--|--|--|
|**レベル5**|課題を達成するまで実行と修正を繰り返し、最後まで粘り強く取り組んでいる。|実行結果やエラーメッセージをもとに試行錯誤を繰り返し、コードを工夫・改善した結果、よりよいプログラムを作成している。|
|**レベル4**|課題の達成を目指して最後まで粘り強く取り組み、実行と修正を繰り返しているが、課題の達成には至っていない。|実行結果やエラーメッセージをもとに試行錯誤を繰り返し、コードを工夫・改善しようとしているが、その工夫が十分な結果につながっていない。|
|**レベル3**|課題に取り組み、実行と修正を繰り返している。|実行結果やエラーメッセージを確認しながら、コードの修正や改善に取り組んでいる。|
|**レベル2**|課題に取り組んでいるが、実行や修正を途中でやめてしまうことが多い。|実行や修正は行っているが、同じような修正を繰り返すことが多く、改善の工夫があまり見られない。|
|**レベル1**|課題への取組がほとんど見られず、実行や修正をほとんど行っていない。|実行結果やエラーメッセージをほとんど確認せず、コードの修正や改善がほとんど見られない。|
