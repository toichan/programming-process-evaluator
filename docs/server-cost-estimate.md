# サーバ維持費・AI API費 試算資料（5ヶ月運用）

**作成日**: 2026/7/5  
**対象システム**: Programming Process Evaluator  
**試算目的**: 5ヶ月運用におけるインフラ費および評価時AI API費の概算算出

## 1. 試算の前提

- 試算対象は **インフラ費 + 評価時AI API費**（人件費・開発費は除外）
- クラウドは AWS（東京リージョン）を想定
- 稼働は24時間365日
- データ保持期間は5ヶ月
- 月ごとの負荷に応じてサーバをリサイズする
- 為替レートは 1USD = 160円（概算）
- 価格は概算のため、実契約時の単価・割引条件・無料枠で変動する

## 2. 運用フェーズ前提（5ヶ月）

- 1ヶ月目: 150アカウント運用
- 2ヶ月目: 150アカウント運用
- 3ヶ月目: 350アカウント運用（ピーク）
- 4ヶ月目: 教師アカウント中心の低負荷運用
- 5ヶ月目: 教師アカウント中心の低負荷運用

## 3. インフラ費（リサイズ運用）

## 4. AI API費（評価時）

### 4.1 API呼び出し回数の前提

- 課題評価対象数: 1,950件
  - 実践校A: 150人 × 5課題 = 750件
  - 実践校B: 200人 × 6課題 = 1,200件
- 再評価率（仮定）: 20%
- 再評価件数: 390件
- 総APIコール数: 2,340件（1,950 + 390）

### 4.2 1コールあたりトークン仮定

- 入力: 12,000 tokens
- 出力: 1,500 tokens

### 4.3 API費の試算

- 低コストモデル（Flash級）: 0.9円 / コール
- 高精度モデル（Pro級）: 9.2円 / コール

計算式:  
`API費 = 総コール数 × 1コール単価`

- Flash級: 2,340 × 0.9 = 2,106円（約0.22万円）
- Pro級: 2,340 × 9.2 = 21,528円（約2.16万円）

## 5. 総費用（5ヶ月）

### 5.1 Flash級モデル利用時

- インフラ費: 160,000円
- API費: 2,106円
- **合計: 162,106円（約16.2万円）**

### 5.2 Pro級モデル利用時

- インフラ費: 160,000円
- API費: 21,528円
- **合計: 181,528円（約18.2万円）**

## 6. 感度（参考）

再評価率が増えるとAPI費は比例して増加する。  
例（Pro級）:

- 再評価率20%: 約2.16万円
- 再評価率50%: 約3.78万円
- 再評価率100%: 約6.01万円

## 7. 取り扱い上の注意

- 本資料は企画・予算化のための概算資料である
- 実際の請求額は、以下の要因で変動する
  - 実測トークン数（プロンプト長・回答長）
  - 実際の外向き通信量
  - 監視ログ保持量
  - AWS料金改定・為替変動
  - リザーブド/スポット等の割引適用有無

## 8. 予算取りの推奨値

- 予算申請時は、変動余地を加味して **20万円（5ヶ月）** を基準値にする
- 安全側に見る場合は **22万円** を上限目安として設定する
