# distribution-state-rules

## 対象

- コード配信機能

## このファイルに記載する内容

- 一覧状態の定義
- クラス別配信状態の定義
- 状態遷移表
- 操作可否マトリクス
- 配信中の編集ルール
- 例外処理一覧
- Servlet / Service / Repository の責務分担

## 初期メモ

- 一覧状態は `下書き` / `配信設定済み` / `配信中` / `配信完了` / `停止` を基本とする。
- クラス別状態は `配信予約` / `配信済み` / `停止` を基本とする。
- `配信中` の編集は未配信クラスのみ対象とし、配信済みクラスはロックする。
