# 画面遷移図（Screen Flow Diagram）

## 目的
本ドキュメントは、プログラミング・プロセス・エバリュエーターの**画面遷移図**です。  
`screen-flow-diagram/webapp/` 以下で実装されるプロトタイプの画面構成と遷移フローを定義します。

**注記**：  
- 本ドキュメントは画面遷移・UI構成の確認を目的としており、実装の詳細設計ではありません  
- 実装時の詳細設計（エラーハンドリング、API仕様など）は別途ドキュメント化します  
- ここで定義した画面遷移は、実装中に変更される可能性があります

### 本実装との対応状況（2026-10-03）

- 下記の「実装済み」は、特記がない限り**画面遷移プロトタイプ**の状況を示す。本実装の工程・完了判定は[実装ロードマップ](./system-configuration/implementation-roadmap.md)と機能別計画を正本とする。
- 本実装済み: 認証、生徒ホーム・同意・アカウント、ID統一、パスワード変更の入力中チェック/サーバー検証・更新後遷移・履歴保存。エディター/対話実行と評価・コードログ・アンケートは主要実装済みだが、各計画の検証残件を維持する。
- 本実装未着手: 授業演習、教師の業務画面、管理者の教師アカウント管理・権限UI。次の着手は授業演習の計画作成。評価・アンケートのユーザー手動確認は設定待ちで保留。
- 管理者学校管理は先行して本実装済み。ただし、2タブ統合/モーダル中心UIはプロトタイプのみで、本実装は従来導線を維持する。統合はロードマップ工程12かつユーザーのローカル反映指示後に行う。

## 実装形式

- **HTML**：`screen-flow-diagram/webapp/WEB-INF/` 以下に配置
- **共通スタイル**：`screen-flow-diagram/webapp/css/template/template.css`
- **ページごとのスタイル**：各フォルダ配下の CSS ファイル
- **スクリプト**：JavaScript（ナビゲーション、モーダル操作など）

## 実装方針

1. 生徒向け画面（実装済み）との共通ヘッダー・ナビゲーション構造を活用
2. 教師向け画面は、サイドメニューナビゲーション + メイン領域の構成を統一
3. 各画面は独立したHTMLファイルとして実装
4. ポップアップ・モーダル表示は JavaScript で実装
5. Bootstrap をベースに、共通CSS で統一デザインを実現

## 共通表示要件

- パソコン・タブレット・スマートフォンで利用できるレスポンシブデザインとし、320 CSS px以上で通常の各画面を表示する。
- 画面幅に応じてナビゲーション、カラム、カード、フォーム、操作ボタンを再配置し、画面幅1024 CSS px未満を理由とする利用案内への置き換えは行わない。
- ページ全体の横方向へのはみ出しを防ぐ。コード編集欄など横幅が必要な領域では、その領域内に限り横スクロールを許容する。
- 画面幅が変わっても、URL・ログイン状態・画面内状態を維持する。

## 画面構成と遷移
本プロトタイプでは、以下の画面構成と遷移を定義します。

### 生徒向け画面構成
- **学生ログイン**
  - 画面項目：ID、パスワード、ログインボタン、説明文
  - 遷移：ログイン成功 → 研究協力同意確認（初回） / 課題選択（2回目以降）
- **アカウント情報**
  - 生徒ID（student_id）はログインIDと同一とし、画面右上・メニュー・登録情報・本人のパスワード操作履歴で統一する。生徒の別表示名は表示しない。教師ID（teacher_id）もログインIDと同一とする
  - パスワード変更画面は[機能仕様書のパスワード変更画面](function-specification.md)に従い、入力中の要件チェック・不足理由・更新ボタンの有効制御を表示する。初回／リセット後の強制変更中は戻るボタンを無効にする
  - パスワード更新成功後は、強制変更ならホーム、通常の任意変更ならアカウント情報へ戻る。遷移先で共通feedbackの完了通知を1回表示する
  - 画面項目：DBから取得した生徒ID、学校情報、クラス情報、初回パスワード変更の要否、パスワード変更可否と導線。レベル名・番号は非表示。変更不可の場合は灰色の無効ボタンと「あなたのアカウントでは、パスワード変更が許可されていません。必要な場合は担当者へご相談ください。」を表示する
  - 遷移：ホームまたは共通ヘッダーのユーザーメニューから遷移し、パスワード変更画面またはホームへ戻る
- **パスワード変更**
  - 画面項目：現在のパスワード、新しいパスワード、新しいパスワード（確認用）、パスワード要件、更新ボタン
  - 遷移：初回ログイン時またはアカウント情報画面から遷移し、更新完了後はアカウント情報画面へ戻る
- **研究協力同意確認**
  - 画面項目：研究協力説明文、同意する・同意しないボタン
  - 遷移：同意完了 → 課題選択、同意しない場合も課題選択へ遷移可能
  - 回答後も共通ヘッダーの「研究同意」から再訪し、回答を変更できる。変更前は確認ダイアログで変更前後の内容と影響を確認し、確定後にホームへ戻る
- **課題選択**
  - 画面項目：初級・中級・上級の課題カード、課題説明、想定入出力例、授業演習導線
  - 遷移：課題選択 → エディター画面 / 授業演習画面
- **授業演習**
  - 画面項目：左側のフォルダ・ファイルツリー、新規フォルダ/新規ファイル作成、Pythonコードエディター、ファイル名タブ行右端のエディター設定ボタン、保存ボタン、実行ボタン、コード欄下側の実行結果カード
  - エディター設定ダイアログでは課題エディターと同じアカウント別設定（文字サイズ10〜24px、コードの折り返し、インデント幅2/4スペース、配色）を使用し、変更は即時反映して両エディターで共有する。初期値は16px、折り返しなし、4スペース、暗色テーマ。コード行数に応じてエディターの縦幅を内容に合わせて広げる。
  - 実行結果はコード編集カードの外に独立カードとしてコード欄の下へ常時表示し、折りたたまない。コード欄の編集幅を保ち、結果は次の実行まで保持する。カード内の「入出力」「エラー」ボタンで表示を切り替え、エラーがある場合は「エラー」ボタンに警告を表示する。「結果は次の実行まで表示されます。」「コードを見ながら確認できます。」の説明文、および「標準出力」「標準エラー」の見出しは表示しない。
  - 遷移：ホームから遷移し、共通ヘッダーまたはホームへ戻る
- **エディター**
  - 画面項目：Pythonコードエディター、実行ボタン、保存ボタン、エディター設定ダイアログ（小さな歯車アイコンの設定ボタンをファイル名タブ行の右端に配置）、課題情報カード（課題・ヒント）、コード欄下の実行結果カード（対話型ターミナル）、コードログ
  - 設定ダイアログでは文字サイズ（10〜24px）、コードの折り返し、インデント幅（2/4スペース）、配色（暗色/明色/高コントラスト）を変更する。変更は即時反映し、ユーザーアカウントへ保存して別端末にも引き継ぐ。設定を初期値に戻せる。初期値は16px、折り返しなし、4スペース、暗色テーマとする。折り返しが無効の場合は、ページ幅を拡大せずエディター内で横スクロールして長い行を確認できる。コード行数に応じてエディターの縦幅を内容に合わせて広げる。
  - 課題情報と実行結果は別々のカードに表示する。課題情報カードは常時表示し、折りたたまない。コード欄と課題情報カードの幅は固定し、幅調整機能を設けない。実行結果カードはコード編集カードの下に常時表示し、折りたたまない。実行結果カードにはターミナル領域を一つだけ配置し、実行中に入力を送信できる入力欄と、入力・標準出力・標準エラーを発生順に表示する履歴を同じ領域に表示する。標準出力と標準エラーのタブ切替や別の標準入力欄は設けず、結果は次の実行まで保持する。「結果は次の実行まで表示されます。」「コードを見ながら確認できます。」の説明文、および「標準出力」「標準エラー」の見出しは表示しない。
  - 実行状態と最終実行時刻はターミナルカード内に表示する。狭い画面でも入力欄をターミナル内に保ち、履歴だけをスクロールできるようにする。
  - 操作：実行ボタンを押したら確認ダイアログを挟まずコードを実行し、ターミナルまで自動スクロールする。プログラムが入力待ちになったらターミナル内で一行ずつ入力して送信し、標準出力と標準エラーを発生順に同じ履歴へ追記する。端末入力・標準出力・標準エラーのいずれも30秒間発生しない場合に実行を終了し、実行全体は最大60秒、CPU使用時間は最大4秒とする。提出ボタンでは「課題を提出しますか？」の事前確認を重ねず、入出力チェック結果のモーダルで内容を確認する。フッターの「提出する」ボタンの直上に「期限内の再提出は可能です」と添えて表示し、最終ボタンの操作で確定する。提出期限内の再提出は対象クラスの設定にかかわらず許可し、教師向けのクラス別再提出設定は設けない。期限後の再提出は許可しない。
  - 遷移：コード実行後はコード欄下のターミナルまでスクロールして、実行状況と対話履歴を表示する。保存時は画面内フィードバックを表示する。提出確定後は評価表示へ
- **評価表示**
  - 画面項目：ルーブリック評価、評価理由、コードログタイムライン、次の課題へのリンク
  - 遷移：評価結果確認 → 課題選択 / アンケート画面
- **アンケート**
  - 画面項目：自己評価、試行錯誤プロセス評価、操作性評価、記述式回答欄
  - 遷移：アンケート完了 → ログアウトまたはトップ画面

### 教師向け画面構成
- **教師ログイン**
  - 画面項目：ID、パスワード、ログインボタン、ロール案内
  - 遷移：ログイン成功 → アカウント情報管理（ダッシュボード代わり）
- **アカウント情報管理**
  - 画面項目：生徒アカウント一覧、生成フォーム、CSVエクスポート、フィルタ
  - 一覧項目：生徒ID、セキュリティレベル、確認可能なパスワード、学校、クラス、初回パスワード変更状態、パスワード変更要求状態、作成日時
  - 作成フォーム項目：学校、クラス、作成件数、セキュリティレベル、初期パスワード
  - 行操作：パスワード確認、パスワードリセット、詳細確認
  - 遷移：機能選択ナビゲーションで各画面へ
  - サイドナビゲーション：課題進捗確認、授業演習コード確認、コード配信、提出課題確認、評価確認、アンケート結果確認、課題編集、プロンプト設計
- **課題進捗確認**
  - 画面項目：生徒進捗一覧（ステータス、経過時間）、詳細遷移
  - 遷移：行クリック → 個別学習履歴詳細
- **授業演習コード確認**
  - 画面項目：生徒一覧、フォルダ/ファイルツリー、コード表示、実行結果
  - 遷移：生徒選択 → ファイル選択 → コード詳細確認
- **コード配信**
  - 画面項目：配信テンプレート編集、対象学校/クラス選択、配信履歴、フィルタ・ソート
  - 遷移：テンプレート作成/更新 → 配信または下書き保存 → 履歴確認
- **提出課題確認**
  - 画面項目：提出一覧、フィルタ・ソート、詳細モーダル、コード確認
  - 遷移：一覧の詳細操作 → 提出課題詳細モーダル
- **評価確認**
  - 画面項目：評価一覧、フィルタ・ソート、詳細表示
  - 遷移：詳細確認 → 評価詳細画面（コードログ表示に遷移可能）
- **アンケート結果確認**
  - 画面項目：アンケート一覧、回答状態、CSVエクスポート
  - 遷移：詳細表示 → 回答詳細画面
- **課題編集**
  - **新規課題作成**
    - 画面項目：課題作成フォーム（課題説明、難易度、テストケース、ヒント情報、初期ルーブリック・プロンプト設定）、課題プレビュー
    - 遷移：作成フォーム → プレビュー → 下書き保存（非公開）、または保存・公開（予約日時があるクラスは日時到来後に公開）
  - **既存課題編集・削除・復元**
    - 画面項目：課題選択一覧（課題名・難易度・対象クラス・作成日時・**作成者**・学習開始状況・改訂番号）、課題内容編集フォーム、論理削除操作、削除済み一覧、下書きへの復元操作、入力チェック警告
    - 未着手の公開課題：課題選択 → 「新しい改訂を編集」確認 → 同一課題系列の要更新改訂を作成 → 編集フォーム → 再公開
    - 学習開始済みの公開課題：課題選択 → 「新しい課題として編集」確認 → 新しい課題系列の下書きを複製 → 編集フォーム → 別課題として公開
    - 学習開始済みの運用変更：課題選択 → 「期限延長・対象追加」確認 → 期限延長または対象クラス追加。期限短縮・既存クラス除外・公開日時後退は不可
    - 削除・復元：削除確認 → 論理削除 → 削除済み一覧 → 復元確認 → 下書き一覧
    - 復元では内容・関連履歴を保持し、公開・予約公開は再開しない。教師が確認して保存・公開を実行する。詳細は[課題状態ルール](state-rules/teacher/task-state-rules.md)を参照。
- **プロンプト設計**
  - **共通プロンプト設計**
    - 画面項目：課題選択、課題内容/プロンプト編集フォーム
    - 遷移：課題選択 → 編集フォーム → 保存
  - **揺らぎ項目対応・再評価**
    - 画面項目：揺らぎ項目表示、対応記述入力欄、追加評価指示入力、再評価実行、履歴表示
    - 遷移：共通プロンプト設計 → 揺らぎ項目確認 → 対応記述入力 → 保存 → 再評価実行
- **教師アカウント管理（admin専用・プロトタイプのみ実装済み）**
  - 画面項目（予定）：教師アカウント一覧、作成フォーム、権限制御、ログイン履歴、削除履歴
  - プロトタイプの遷移：教師ログイン（admin）→ 管理者画面。教師アカウント管理と学校管理を同じ画面のタブで切り替える。本実装は従来の管理者ホーム・学校管理を維持し、反映はユーザーの明示指示待ち

- **学校管理（admin専用）**
  - 本実装の入口は従来の管理者ホームの管理メニューリンク。サブページのパンくず・戻る導線は、本実装への反映指示まで維持する。
  - プロトタイプ入口: [管理者画面](../screen-flow-diagram/webapp/WEB-INF/admin/management.html)。教師アカウント管理／学校管理の2タブとし、一覧を中心に表示する。教師新規作成・権限編集・個別履歴・全体操作履歴、学校登録・詳細編集はモーダルで表示。常時表示の作成フォーム・全体履歴と独立した管理者ホームは廃止する。
  - 統合画面のファイル名は`management.html`とし、旧ホーム・旧学校管理の互換ページは削除済み。教師ログインからの管理者導線も統合画面へ更新する。[学校タブを直接表示](../screen-flow-diagram/webapp/WEB-INF/admin/management.html?tab=schools)できる。本実装への反映はロードマップ工程12まで保留する。
  - デザイン・挙動変更はプロトタイプ専用CSS/JSで完結し、本実装側の共有資産を参照・変更しない。学校操作はページ内サンプルのみ（再読込で初期化）、教師操作は従来のブラウザー内サンプルのみでDBには保存されない。編集モーダルを閉じてから共通確認を開き、キャンセルでは入力値を保持して編集へ戻す。
  - 統合後のブラウザー確認: 教師検索・権限編集・新規作成・個別/全体履歴、学校のロック表示・登録/編集・確認キャンセル、375pxで両タブと作成モーダルの横はみ出しなしを確認。教師作成と結果表示のモーダル、学校編集と確認のモーダルが重ならないことを確認。改名後はログインから`management.html`への遷移と学校タブ直接表示を確認し、旧ページ参照は除去済み。確認用教師と権限変更は復元済み。CSV出力・削除・PW再設定の全操作回帰は今回未実施。
  - 学校一覧から学校詳細・編集へ進み、学校登録フォームで学校名とセキュリティレベル1/2を設定する。学校コードは自動発行する
  - 生徒登録後のレベルは変更不可と表示し、学校名だけ変更できる。更新確認は共通feedbackを使用する
  - プロトタイプは上記統合画面の学校管理タブ。本実装URLは `/admin/schools`のまま維持し、本実装の登録・更新後は詳細へ戻り、DB保存結果を表示する
  - 教師の生徒作成プロトタイプは登録済み学校のレベルを参照専用表示し、個別選択を廃止する。プロトタイプの学校候補は表示用サンプルであり、本実装では権限のある学校をDBから取得する

### 画面間遷移のイメージ
**生徒側**：
1. ログイン後、初回かどうかで「同意確認」または「課題選択」へ進む
2. 共通ヘッダーのユーザーメニューから、必要に応じてアカウント情報画面を確認する
3. セキュリティレベル2の生徒は、必要に応じてパスワード変更画面からパスワードを更新する
4. ホームから課題演習または授業演習を選択する
5. 課題演習ではエディターに進み、コード実行・保存を行う
6. エディターでの成果は評価画面に反映され、必要に応じてアンケートへ遷移する

**教師側**：
1. ログイン → アカウント管理画面（初期表示）
2. サイドメニューから目的の機能を選択
3. 各機能内で「一覧 → 詳細」のフローを繰り返す
4. 必要に応じてCSVエクスポート、再評価実行などの操作を実行
5. （未実装）adminログイン時は教師アカウント管理へ遷移

## 教員向け機能の共通デザイン方針

画面遷移図実装時に従う基本方針：

### ナビゲーション構造
- **共通ヘッダー**：ロゴ、教師情報、ログアウトボタンを配置（生徒向けに準じる）
- **サイドメニュー**：アカウント情報管理を入口として、以下機能を選択可能
  - 課題進捗確認
  - 授業演習コード確認
  - コード配信
  - 提出課題確認
  - 評価確認
  - アンケート結果確認
  - 課題編集
  - プロンプト設計
- **パンくずナビゲーション**：詳細画面で現在位置を明示

### 共通要素
- **リスト画面**：テーブル形式で表示、ソート・フィルタ機能搭載
- **詳細画面**：行クリックで遷移、タブ分けで複数情報を管理
- **エクスポート機能**：CSVダウンロード（UTF-8 BOM付き）
- **確認ダイアログ**：削除・再評価などの重要操作前に表示
- **エラー通知**：トースト表示またはモーダル確認
- **日時表示**：`YYYY-MM-DD HH:MM:SS` で統一

### 画面遷移の基本フロー
1. ログイン → アカウント管理（初期画面）
2. サイドメニューで機能選択 → 一覧画面
3. 一覧から行選択 → 詳細画面
4. 詳細から操作（エクスポート、再評価など）→ 確認ダイアログ → 実行
