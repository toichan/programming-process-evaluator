# 画面遷移図（Screen Flow Diagram）

## 目的
`screen-flow-diagram/webapp/WEB-INF/template/template.html` は、今回の機能仕様書に基づき画面遷移とデザインを確認するためのプロトタイプです。デザイン確認用のテンプレートとして作成し、最終的な実装は `screen-flow-diagram` 配下で進めます。

## 対象範囲
本プロトタイプでは、以下の機能仕様書の全体を対象とします：

- 生徒向け機能
  - アカウント機能（ログイン / ログアウト）
  - 研究協力同意確認
  - 課題提示・課題選択
  - エディター機能（Pythonコード編集・実行・保存）
  - ルーブリック表示・評価表示
  - アンケート機能
- 教師向け機能
  - アカウント情報管理
  - 課題作成機能
  - 学習履歴確認機能
  - 評価確認機能
  - アンケート結果確認機能

## 実装場所
- HTMLテンプレート: `screen-flow-diagram/webapp/WEB-INF/template/template.html`
- 共通スタイル: `screen-flow-diagram/webapp/css/template/template.css`

## 進め方
1. まず `template.html` 上で対象範囲と画面構成を整理し、画面遷移図として確認する。  
2. フォルダ構成を確定し、優先度の高い画面から順番に実装を進める。  
3. ポップアップやモーダル表示は JavaScript で実装する。  
4. デザイン確認用テンプレートは、実装前のUI確認を目的として維持する。

## 現在の状態
- `template.html` に画面遷移の見立てと、生徒向け/教員向けの主要画面リストを記載済み。
- `template.css` にBootstrapベースの共通デザインスタイルを定義済み。

## 次のステップ
1. フォルダ構成を決める
2. 優先度の高い生徒向け画面を作成する
   - ログイン画面
   - 研究協力同意確認画面
   - 課題選択画面
   - エディター画面
   - 評価表示画面
3. その後、教師向け画面を順次追加する
4. 最終的に全体の画面遷移が確認できる形へまとめる

## 画面構成と遷移
本プロトタイプでは、以下の画面構成と遷移を定義します。

### 生徒向け画面構成
- **学生ログイン**
  - 画面項目：ID、パスワード、ログインボタン、説明文
  - 遷移：ログイン成功 → 研究協力同意確認（初回） / 課題選択（2回目以降）
- **研究協力同意確認**
  - 画面項目：研究協力説明文、同意する・同意しないボタン
  - 遷移：同意完了 → 課題選択、同意しない場合も課題選択へ遷移可能
- **課題選択**
  - 画面項目：初級・中級・上級の課題カード、課題説明、想定入出力例
  - 遷移：課題選択 → エディター画面
- **エディター**
  - 画面項目：Pythonコードエディター、実行ボタン、保存ボタン、実行結果表示、課題情報パネル
  - 遷移：実行 / 保存のフィードバック、ルーブリック表示モーダル、課題完了後は評価表示へ
- **評価表示**
  - 画面項目：ルーブリック評価、評価理由、コードログタイムライン、次の課題へのリンク
  - 遷移：評価結果確認 → 課題選択 / アンケート画面
- **アンケート**
  - 画面項目：自己評価、試行錯誤プロセス評価、操作性評価、記述式回答欄
  - 遷移：アンケート完了 → ログアウトまたはトップ画面

### 教師向け画面構成
- **教師ログイン**
  - 画面項目：ID、パスワード、ログインボタン、ロール案内
  - 遷移：ログイン成功 → アカウント情報管理
- **アカウント情報管理**
  - 画面項目：生徒アカウント一覧、生成フォーム、CSVエクスポート、フィルタ
  - 遷移：新規作成 / 編集 / エクスポート
- **課題作成**
  - 画面項目：課題説明入力、制約入力、テストケース入力、Pythonコマンド仕様入力
  - 遷移：作成完了 → 課題一覧 / 公開設定
- **学習履歴確認**
  - 画面項目：生徒進捗一覧、ステータス、経過時間、詳細遷移
  - 遷移：行クリック → 個別学習履歴詳細
- **評価確認**
  - 画面項目：評価一覧、絞り込み、詳細表示、グラフ/視覚表現
  - 遷移：詳細確認 → 評価詳細画面
- **アンケート結果確認**
  - 画面項目：アンケート一覧、回答状態、記述式展開、CSVエクスポート
  - 遷移：詳細表示 → 回答詳細画面

### 画面間遷移のイメージ
1. 生徒はログイン後、初回かどうかで「同意確認」または「課題選択」へ進む。  
2. 課題選択からエディターに進み、コード実行・保存を行う。  
3. エディターでの成果は評価画面に反映され、必要に応じてアンケートへ遷移する。  
4. 教師はログイン後、アカウント管理・課題作成・学習履歴確認・評価確認・アンケート結果確認を順に操作できる。  
5. 画面遷移は基本的に「一覧 → 詳細 / 編集 → 保存・完了」の流れを繰り返す形とする。

### フォルダ配置との対応
- `WEB-INF/student/account`：学生ログイン / 同意確認などの認証・メニュー開始画面
- `WEB-INF/student/menu`：課題選択やメニュー遷移を管理
- `WEB-INF/student/editor`：コード編集・実行・保存画面
- `WEB-INF/student/evaluation`：評価表示・ルーブリック表示画面
- `WEB-INF/student/survey`：アンケート画面
- `WEB-INF/teacher/account`：教師ログイン・アカウント管理画面
- `WEB-INF/teacher/task`：課題作成画面
- `WEB-INF/teacher/history`：学習履歴確認画面
- `WEB-INF/teacher/evaluation`：評価確認画面
- `WEB-INF/teacher/survey`：アンケート結果確認画面
