# 画面遷移図（Screen Flow Diagram）

## 目的
本ドキュメントは、プログラミング・プロセス・エバリュエーターの**画面遷移図**です。  
`screen-flow-diagram/webapp/` 以下で実装されるプロトタイプの画面構成と遷移フローを定義します。

**注記**：  
- 本ドキュメントは画面遷移・UI構成の確認を目的としており、実装の詳細設計ではありません  
- 実装時の詳細設計（エラーハンドリング、API仕様など）は別途ドキュメント化します  
- ここで定義した画面遷移は、実装中に変更される可能性があります

## 対象範囲

本ドキュメントで画面遷移を定義する機能：

**生徒向け機能**（実装済み）
- アカウント機能（ログイン / ログアウト）
- アカウント情報確認
- 研究協力同意確認
- 課題提示・課題選択
- エディター機能（Pythonコード編集・実行・保存）
- ルーブリック表示・評価表示
- コードログ表示

**教師向け機能**（実装予定）
- アカウント情報管理機能（優先度：中）
- 学習履歴確認機能（優先度：高）
- 評価確認機能（優先度：高）
- アンケート結果確認機能（優先度：低）
- 課題編集機能（優先度：中）
  - 新規課題作成
  - 既存課題編集・削除
- プロンプト修正機能（優先度：中）
  - 共通プロンプト修正
  - 揺らぎ項目対応・再評価

## 実装形式

- **HTML**：`screen-flow-diagram/webapp/WEB-INF/` 以下に配置
- **共通スタイル**：`screen-flow-diagram/webapp/css/template/template.css`
- **ページごとのスタイル**：各フォルダ配下の CSS ファイル
- **スクリプト**：JavaScript（ナビゲーション、モーダル操作など）

## 実装方針

1. 生徒向け画面（実装済み）との共通ヘッダー・ナビゲーション構造を活用
2. 教師向け画面は、サイドメニューナビゲーション + メイン領域の構成を統一
3. 各画面は独立したHTMLファイルとして実装
4. ポップアップ・モーダル表示は JavaScript で実装
5. Bootstrap をベースに、共通CSS で統一デザインを実現

## 画面構成と遷移
本プロトタイプでは、以下の画面構成と遷移を定義します。

### 生徒向け画面構成
- **学生ログイン**
  - 画面項目：ID、パスワード、ログインボタン、説明文
  - 遷移：ログイン成功 → 研究協力同意確認（初回） / 課題選択（2回目以降）
- **アカウント情報**
  - 画面項目：生徒ID、学校情報、クラス情報、セキュリティレベル、パスワード運用ルール、パスワード変更導線
  - 遷移：ホームまたは共通ヘッダーのユーザーメニューから遷移し、パスワード変更画面またはホームへ戻る
- **パスワード変更**
  - 画面項目：現在のパスワード、新しいパスワード、新しいパスワード（確認用）、パスワード要件、更新ボタン
  - 遷移：初回ログイン時またはアカウント情報画面から遷移し、更新完了後はアカウント情報画面へ戻る
- **研究協力同意確認**
  - 画面項目：研究協力説明文、同意する・同意しないボタン
  - 遷移：同意完了 → 課題選択、同意しない場合も課題選択へ遷移可能
- **課題選択**
  - 画面項目：初級・中級・上級の課題カード、課題説明、想定入出力例
  - 遷移：課題選択 → エディター画面
- **エディター**
  - 画面項目：Pythonコードエディター、実行ボタン、保存ボタン、実行結果表示、課題情報パネル
  - 遷移：実行 / 保存のフィードバック、ルーブリック表示モーダル、課題完了後は評価表示へ
- **評価表示**
  - 画面項目：ルーブリック評価、評価理由、コードログタイムライン、次の課題へのリンク
  - 遷移：評価結果確認 → 課題選択 / アンケート画面
- **アンケート**
  - 画面項目：自己評価、試行錯誤プロセス評価、操作性評価、記述式回答欄
  - 遷移：アンケート完了 → ログアウトまたはトップ画面

### 教師向け画面構成
- **教師ログイン**
  - 画面項目：ID、パスワード、ログインボタン、ロール案内
  - 遷移：ログイン成功 → アカウント情報管理（ダッシュボード代わり）
- **アカウント情報管理**
  - 画面項目：生徒アカウント一覧、生成フォーム、CSVエクスポート、フィルタ
  - 一覧項目：生徒ID、セキュリティレベル、確認可能なパスワード、学校、クラス、初回パスワード変更状態、パスワード変更要求状態、作成日時
  - 作成フォーム項目：学校、クラス、作成件数、セキュリティレベル、初期パスワード
  - 行操作：パスワード確認、パスワードリセット、詳細確認
  - 遷移：機能選択ナビゲーションで各画面へ
  - サイドナビゲーション：学習履歴確認、評価確認、アンケート結果確認、課題編集、プロンプト修正
- **学習履歴確認**
  - 画面項目：生徒進捗一覧（ステータス、経過時間）、詳細遷移
  - 遷移：行クリック → 個別学習履歴詳細
- **評価確認**
  - 画面項目：評価一覧、フィルタ・ソート、詳細表示
  - 遷移：詳細確認 → 評価詳細画面（コードログ表示に遷移可能）
- **アンケート結果確認**
  - 画面項目：アンケート一覧、回答状態、CSVエクスポート
  - 遷移：詳細表示 → 回答詳細画面
- **課題編集**
  - **新規課題作成**
    - 画面項目：課題作成フォーム（課題説明、難易度、テストケース、ヒント情報、初期ルーブリック・プロンプト設定）、課題プレビュー
    - 遷移：作成フォーム → プレビュー → 保存・公開
  - **既存課題編集・削除**
    - 画面項目：課題選択、課題内容編集フォーム、論理削除操作、入力チェック警告
    - 遷移：課題選択 → 編集フォーム → 保存、または削除確認 → 論理削除
- **プロンプト修正**
  - **共通プロンプト修正**
    - 画面項目：課題選択、課題内容/プロンプト編集フォーム
    - 遷移：課題選択 → 編集フォーム → 保存
  - **揺らぎ項目対応・再評価**
    - 画面項目：揺らぎ項目表示、対応記述入力欄、追加評価指示入力、再評価実行、履歴表示
    - 遷移：共通プロンプト修正 → 揺らぎ項目確認 → 対応記述入力 → 保存 → 再評価実行

### 画面間遷移のイメージ
**生徒側**：
1. ログイン後、初回かどうかで「同意確認」または「課題選択」へ進む
2. 共通ヘッダーのユーザーメニューから、必要に応じてアカウント情報画面を確認する
3. セキュリティレベル2の生徒は、必要に応じてパスワード変更画面からパスワードを更新する
4. 課題選択からエディターに進み、コード実行・保存を行う
5. エディターでの成果は評価画面に反映され、必要に応じてアンケートへ遷移する

**教師側**：
1. ログイン → アカウント管理画面（初期表示）
2. サイドメニューから目的の機能を選択
3. 各機能内で「一覧 → 詳細」のフローを繰り返す
4. 必要に応じてCSVエクスポート、再評価実行などの操作を実行

### フォルダ配置との対応
**生徒向け**（実装済み）：
- `WEB-INF/student/account`：学生ログイン / アカウント情報などの認証・アカウント関連画面
- `WEB-INF/student/home`：課題選択やメニュー遷移を管理
- `WEB-INF/student/editor`：コード編集・実行・保存画面
- `WEB-INF/student/evaluation`：評価表示・ルーブリック表示画面（log.html を含む）
- `WEB-INF/student/survey`：アンケート画面

**教師向け**（実装予定）：
- `WEB-INF/teacher/account`：教師ログイン・アカウント管理画面
- `WEB-INF/teacher/history`：学習履歴確認画面
- `WEB-INF/teacher/evaluation`：評価確認画面
- `WEB-INF/teacher/survey`：アンケート結果確認画面
- `WEB-INF/teacher/task`：課題編集画面（新規課題作成、既存課題編集・削除を管理）
- `WEB-INF/teacher/prompt`：プロンプト修正画面（共通プロンプト修正、揺らぎ項目対応・再評価を管理）

この構成をもとに、各画面を段階的に実装します。

## 教員向け機能の共通デザイン方針

画面遷移図実装時に従う基本方針：

### ナビゲーション構造
- **共通ヘッダー**：ロゴ、教師情報、ログアウトボタンを配置（生徒向けに準じる）
- **サイドメニュー**：アカウント情報管理を入口として、以下機能を選択可能
  - 学習履歴確認
  - 評価確認
  - アンケート結果確認
  - 課題編集
  - プロンプト修正
- **パンくずナビゲーション**：詳細画面で現在位置を明示

### 共通要素
- **リスト画面**：テーブル形式で表示、ソート・フィルタ機能搭載
- **詳細画面**：行クリックで遷移、タブ分けで複数情報を管理
- **エクスポート機能**：CSVダウンロード（UTF-8 BOM付き）
- **確認ダイアログ**：削除・再評価などの重要操作前に表示
- **エラー通知**：トースト表示またはモーダル確認
- **日時表示**：`YYYY-MM-DD HH:MM:SS` で統一

### 画面遷移の基本フロー
1. ログイン → アカウント管理（初期画面）
2. サイドメニューで機能選択 → 一覧画面
3. 一覧から行選択 → 詳細画面
4. 詳細から操作（エクスポート、再評価など）→ 確認ダイアログ → 実行

## 次フェーズ

本ドキュメントで画面遷移を確定した後、以下の流れで実装を進めます：

1. **Servletコントローラの実装**：ログイン、各機能の入口
2. **JSPビューの実装**：共通テンプレート化し、各画面を段階実装
3. **JavaScriptの実装**：フィルタ、ソート、AJAX自動更新
4. **スタイル調整**：Bootstrap + 独自CSS で統一UI実現
