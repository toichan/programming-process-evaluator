# 本番運用条件の決定テンプレート

## 目的

この文書は、[開発からデプロイまでの全体手順](./development-and-deployment-flow.md) の「10. この文書だけでは確定していないこと」に挙げた本番運用上の未決事項を、実装と並行して決定・記録するための枠組みです。

本番運用条件（AWSリージョン・予算、ドメイン・DNS・TLS、DBバックアップ、Gemini API上限、デプロイ体制、監視・障害対応）は、契約者・研究実施者および必要に応じて学校・大学による意思決定（契約・予算承認・担当者アサイン）を要するため、この文書では未決の数値や固有名詞を決め打ちしません。各項目について「推奨デフォルト（一般的な小規模運用でよく採用される案）」と「決定に必要な確認事項」を示し、実際の決定内容と決定日・決定者を追記していく運用とします。

機能実装（IC-002〜IC-009）は、本番運用条件の確定を待たずに進められます。本番公開の準備段階に入る前に、本文書の各項目を「決定済み」にしてください。

## 使い方

- 各項目の「決定状況」を、`未確定` → `検討中` → `決定済み` の順で更新します。
- `決定済み` にする際は、決定内容・決定日・決定者・根拠（稟議、契約、担当者間の合意メモ等）を記録します。
- 推奨デフォルトは仮の出発点であり、組織のポリシーやコストの都合で変更して構いません。
- 決定後は、[開発からデプロイまでの全体手順](./development-and-deployment-flow.md) の該当箇所、および必要であれば `.env` / 本番用 Compose 設定へ反映します。
