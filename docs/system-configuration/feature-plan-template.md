# 機能別実装計画テンプレート

このテンプレートは、[実装ロードマップ](./implementation-roadmap.md)の工程から、直近で実装する機能を切り出して作業前に確認するためのものです。大規模な機能や複数画面に及ぶ変更では、コピーして機能別計画書として使います。小さな変更では会話内で埋めても構いません。

```markdown
# [機能名] 実装計画

## 目的と範囲
- 利用者に提供する動作:
- 今回実装する範囲:
- 今回対象外:

## 必読資料
- 機能仕様書:
- 画面遷移図 / プロトタイプ:
- 状態ルール:
- DB 設計・テーブル定義:
- クラス図 / AI連携設計 / その他:

## 前提・未決事項
- 合意済み前提:
- 実装契約上の関連 ID:
- 未決事項・影響・確認が必要な相手:

## ユースケースとデータ契約
| 操作 | ロール・所有範囲 | 入力 | DBから読むデータ | DBへの変更 | 状態遷移 | 成功・失敗時の表示 |
|---|---|---|---|---|---|---|
| | | | | | | |

## 実装タスク
1. [ ] DB migration / 初期データ:
2. [ ] Entity / DTO / DAO:
3. [ ] Service とトランザクション:
4. [ ] Servlet / Filter / 入力検証:
5. [ ] JSP / CSS / JavaScript:
6. [ ] 認可・監査・エラー処理:
7. [ ] テスト・手動確認:

## 変更予定ファイル
- 作成:
- 変更:
- プロトタイプから再利用する表示資産:
- プロトタイプから除去する仮データ・擬似動作:

## 検証計画
- ビルド / テストコマンド:
- 正常系:
- 状態遷移・操作可否:
- 権限境界・直接 URL:
- DB保存後の再読込:
- 異常系:
- 未実施の場合に残る未確認事項:

## 完了条件
- [ ] 機能仕様・画面導線に合致する
- [ ] 関連する状態ルールと DB 状態値に合致する
- [ ] 業務データを DB から読み書きする
- [ ] サーバー側でロール・所有範囲・状態遷移を検証する
- [ ] 仮データ・擬似成功処理・秘密情報を残していない
- [ ] 実行した確認結果と未確認事項を記録した
```

## 作成・保存ルール

- ファイルとして残す価値がある複数段階・複数担当の機能だけ、同じフォルダに `feature-plans/<機能名>.md` として保存します。
- 単一チャット内で完了する小さな変更では、計画ファイルを増やさず、作業前の確認内容と完了条件を会話に記録します。
- どの形式でも、設計上の未決事項を確定済みとして記載せず、合意前は実装へ進みません。
